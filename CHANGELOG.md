# Changelog

All notable changes to `pi-reflex`. Releases are published by pushing a `v*`
tag (CI-only; see [docs/PUBLISHING.md](docs/PUBLISHING.md)).

## Unreleased

- **Artifact integrity**: downloads are verified against `checksums.json`
  (sha256 + size, pinned in the npm package and generated by
  `npm run checksums`); a mismatch discards the file and fails loudly.
  Cache hits are size-checked against the pins. Escape hatch:
  `PI_REFLEX_NO_CHECKSUM_VERIFY=1`.
- **Downloader hardening**: a body that ends short of `content-length` is
  retried instead of being promoted as complete; a lockfile serializes
  downloads between the extension and the MCP server (two processes sharing
  `~/.pi-reflex/engines`).
- **CI**: typecheck (src + tests), unit tests and build now run on every
  push/PR, on ubuntu and windows runners (`.github/workflows/ci.yml`).
  Tests are typechecked for the first time (`npm run typecheck:tests`,
  `tsconfig.test.json`).
- **MCP**: `serverInfo.version` now tracks `package.json` (was stuck at
  0.0.1); tools advertise `outputSchema`; the hand-written schemas are
  asserted deeply equal to the typebox source of truth (`src/extension/schemas.ts`).
- `strict` tightened: `exactOptionalPropertyTypes` enabled.
- Dropped the unused `Engine.predict` alias for `systemOne`.
- Guard regression test fixed: the "tripped stays inert" case previously
  passed via an accidental loader throw instead of exercising inertness.
- `typebox` peer range pinned to `>=1.0.0`.
